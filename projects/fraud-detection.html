Personal project · 2024

Fraud detection with machine learning and deep learning

Fraud is rare, so a model can be 99.9% accurate and still miss most of it. This project compares traditional models with neural networks and judges them on the fraud class itself, because a missed fraud costs more than a false alarm.

Role
Builder
When
2024
Where
Personal project
Data
~285K card transactions
0.97 / 0.77precision and recall on the rare fraud class

What I did

  • Balanced the training data with SMOTE, selected features with recursive feature elimination and scaled the inputs.
  • Tuned random forest, SVM, logistic regression and KNN with randomized search.
  • Built LSTM, GRU and dense networks in TensorFlow/Keras, tuned with Keras Tuner Hyperband, with early stopping and dropout against overfitting.
  • Compared models on confusion matrices and classification reports, with the focus on fraud-class recall.

Result

The reported model reached 0.97 precision and 0.77 recall (F1 0.86) on the fraud class, on a test set of 56,962 transactions with 98 frauds.

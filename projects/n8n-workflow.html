How it works

  • Command-based routing gates every LLM action behind a deterministic trigger, so the workflow behaves predictably.
  • Claude (through an enterprise gateway) pulls action items out of a meeting transcript as validated JSON.
  • Fan-out logic creates one monday.com group per meeting and one task per action item.
  • Project charters and data-enablement plans are written straight into Google Slides and Docs templates.
  • Integrations with Google Workspace, monday.com and Redis use API/OAuth with data mapping between nodes.

Where it is now

It got a lot of attention internally, and we have since rebuilt it on an internal platform. The new version reads a project's Google Drive folder, where the transcripts and project files are stored, and drafts the project charter, stakeholder matrix, action items, business case, risk register and business requirements document.

Work details are generalized, and the simulation uses simulated data.

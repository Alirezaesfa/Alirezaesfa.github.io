Backlog triage agent on the Claude API

I built it over raw REST first to learn exactly what goes back and forth with the model, then moved it to the official Anthropic Python SDK.

What it does

  • Tool calling with JSON Schema tool definitions and a multi-tool agent loop that runs until the model gives a final answer.
  • Retrieval-augmented generation (RAG) with a ChromaDB vector store, so it checks similar past items first.
  • An evaluation suite that checks it picks the right tools and returns the expected priority for known inputs.

The core loop

# keep going until Claude stops asking for tools
while True:
    response = client.messages.create(
        model=MODEL, max_tokens=1024,
        tools=TOOLS, messages=messages)
    messages.append({"role": "assistant", "content": response.content})
    if response.stop_reason != "tool_use":
        break
    results = [run_tool(b) for b in response.content if b.type == "tool_use"]
    messages.append({"role": "user", "content": results})

The public repository has the first REST scripts so far; the SDK, RAG and evaluation code is being added.

AI product finder with RAG on the Claude SDK

A personal project that runs on my laptop. A search-style web page takes what a customer needs in plain words; a Claude SDK agent with tool calling searches a product catalog through RAG and recommends a product or a bundle that fits.

What it does

  • A search-style web page: the user types a problem or need in plain words and gets a product or a bundle of products from a catalog of 628 products.
  • A Claude SDK agent with tool calling decides when to search, and retrieval-augmented generation (RAG) over ChromaDB finds the catalog sections that match, grouped by product.
  • Tested on a 16-question evaluation set: I compared three Claude models and prompt designs, and chose the setup that rephrases each need into several searches.
  • It grew out of my first agent, which answers questions about an annual report and cites the page. I built that one over raw HTTP first, then on the SDK, and tested it with an evaluation suite (not in the public repository yet).

The core loop

# keep going until Claude stops asking for tools
while True:
    response = client.messages.create(
        model=MODEL, max_tokens=1024,
        tools=TOOLS, messages=messages)
    messages.append({"role": "assistant", "content": response.content})
    if response.stop_reason != "tool_use":
        break
    results = [run_tool(b) for b in response.content if b.type == "tool_use"]
    messages.append({"role": "user", "content": results})

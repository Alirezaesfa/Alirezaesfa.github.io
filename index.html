Personal project · 2026 · Python, Claude API, ChromaDB

Backlog Triage Agent

An agent that reads a backlog item and recommends a priority. I built it over raw REST first to learn exactly what goes back and forth with the model, then moved it to the official Anthropic Python SDK.

  • Tool calling with JSON Schema definitions and a multi-tool agent loop
  • Retrieval-augmented generation (RAG) with ChromaDB, so it checks similar past items first
  • An evaluation suite that checks it picks the right tools and returns the expected priority

The public repository has the first REST scripts so far; the SDK, RAG and evaluation code is being added.

agent loop, simplified
# keep going until Claude stops asking for tools
while True:
    response = client.messages.create(
        model=MODEL, max_tokens=1024,
        tools=TOOLS, messages=messages)
    messages.append({"role": "assistant",
                     "content": response.content})
    if response.stop_reason != "tool_use":
        break
    results = [run_tool(b) for b in response.content
               if b.type == "tool_use"]
    messages.append({"role": "user", "content": results})
